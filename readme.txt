A lightweight, scalable widgets kit for Ele page builder users.

== Description ==

Ele Widgets Kit is a performance-focused widgets library built for users of the Ele page builder.

It follows WordPress coding standards, avoids unnecessary bloat, and provides a clean developer-friendly architecture.

Features:
* Clean, optimized Elementor widget structure
* Fully object-oriented and namespaced
* Widget enable/disable system
* Dynamic CSS & JS loading per widget
* Translation ready
* Pro-ready architecture

This plugin is not affiliated with or endorsed by Elementor.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the Plugins menu
3. Open Ele page builder and start using widgets

== Frequently Asked Questions ==

= Does this plugin require Elementor? =
Yes. Ele Widgets Kit works only when Elementor is active.

= Does it slow down my website? =
No. Assets are loaded dynamically only when required.

= Is this plugin free? =
Yes. A Pro version with advanced widgets may be available separately.
