# Ele Widgets Kit

A widget kit for Elementor with an example widget and an admin screen for enabling widgets.

## Installation and use

1. Place the `ele-widgets-kit` folder in `wp-content/plugins/`.
2. Activate Ele Widgets Kit in the WordPress Plugins screen.

Activate Elementor first, then enable the desired widgets and open the Elementor editor.
